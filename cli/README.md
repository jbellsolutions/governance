# gov — governance CLI (Printing Press)

`gov` is an agent-native CLI for the Paperclip governance API — list/create/update companies,
agents, projects, routines, issues, and run imports — generated by
[Printing Press](https://printingpress.dev) from [`paperclip-governance.openapi.yaml`](./paperclip-governance.openapi.yaml).
The generator also emits a **Claude Code skill** (`gov/SKILL.md`) and an **MCP server**
(`gov/cmd/gov-pp-mcp`), so the same surface is usable from the terminal, from Claude Code, and over MCP.

## Build

```bash
cd cli/gov
go build -o build/stage/bin/gov-pp-cli ./cmd/gov-pp-cli   # CLI
go build -o build/stage/bin/gov-pp-mcp ./cmd/gov-pp-mcp    # MCP server
```

(The committed source excludes `build/` artifacts — see `cli/gov/.gitignore`.)

## Configure

```bash
export GOV_BOARD_KEY="pcp_board_…"     # board key (auth)
# host comes from the spec's server; override per-machine:
gov-pp-cli auth set-token "$GOV_BOARD_KEY"
# or set base_url in ~/.config/gov-pp-cli/config.toml
gov-pp-cli doctor --agent               # verify auth + connectivity
```

## Use (examples — all verified live)

```bash
gov-pp-cli companies list --agent
gov-pp-cli companies get-company <companyId> --compact
gov-pp-cli companies agents list <companyId> --agent
gov-pp-cli companies create-company --help        # spin up a business
gov-pp-cli companies routines list <companyId>    # what makes a team run on its own
gov-pp-cli companies imports ...                  # import a team package
gov-pp-cli api                                    # browse all interfaces
gov-pp-cli which "create a company"               # find the command for a capability
```

`--agent` turns on JSON + non-interactive + compact output for agent/script use.

## Regenerate (after editing the spec)

```bash
cli-printing-press generate --spec ./paperclip-governance.openapi.yaml --name gov --output ./gov --force
```

Install the generator: `go install github.com/mvanhorn/cli-printing-press/v4/cmd/cli-printing-press@latest`
(Go 1.26.3+; toolchain auto-fetch handles it). To generate via the interactive Claude Code flow
instead: `npx skills add mvanhorn/cli-printing-press/skills --skill '*' -g -a claude-code -y`, then
`/printing-press <spec or site>`.

## Notes

- The spec is hand-authored (Paperclip exposes no OpenAPI document). The CLI currently covers
  companies, agents, and issues interfaces; extend the spec and regenerate to add more.
- `gov/SKILL.md` is the Printing-Press-generated skill describing this CLI to agents; it complements
  the higher-level `plugins/governance` skills (which orchestrate businesses/departments).
